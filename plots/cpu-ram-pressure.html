CPU vs RAM — warm and per-exec firecracker

Red mesh: warm (resident) firecracker. Blue mesh: per-exec (start/stop) firecracker. Iso-pressure lines (constant N, every 5). Iso-duty lines (constant D, every 3 %, 0–12 %).

Warm: CPU = N × D × 2.11 vCPU; RAM = N × 0.307 GiB (duty-invariant). Per-exec: CPU = N × D × 4.65 vCPU; RAM = N × 0.07 + N × D × 1.16 GiB (base + cold-rootfs page cache). Bisector: 1 vCPU = 1 GiB. Source: moca-side-by-side-report.md.
